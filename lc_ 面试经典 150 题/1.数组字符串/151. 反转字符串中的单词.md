### 常用字符串函数速查

#### 1. `strip()` 和 `split()` 的用法

- **`strip([chars])`**:
  - **作用**: 用于移除字符串头尾指定的字符（默认为所有空白符，包括空格、换行符 `\n`、制表符 `\t` 等）。
  - **用法**: `s.strip()`。
  - **示例**: `"  hello world  ".strip()` 返回 `"hello world"`。
  - **变体**: `lstrip()` 只移除左边空白，`rstrip()` 只移除右边空白。

- **`split([sep[, maxsplit]])`**:
  - **作用**: 通过指定分隔符对字符串进行切片，返回一个字符串列表。如果未指定分隔符（默认），则以所有空白符（连续空格、换行、制表符等）作为分隔符，并且会自动丢弃连续的空白符（即不会出现空字符串元素）。
  - **用法**: `s.split()`。
  - **示例**: `"a   b c".split()` 返回 `['a', 'b', 'c']`。

#### 2. 其他常用字符串函数

- **`join(iterable)`**: 将序列（如列表）中的元素以指定的字符连接生成一个新的字符串。例如: `" ".join(["hello", "world"])` 返回 `"hello world"`。
- **`replace(old, new[, count])`**: 将字符串中的子串 `old` 替换成 `new`，如果指定 `count`，则替换不超过 `count` 次。
- **`find(sub)`**: 检测 `sub` 是否包含在字符串中，存在则返回第一次出现的索引，否则返回 `-1`。
- **`index(sub)`**: 和 `find()` 类似，但如果 `sub` 不存在会抛出 `ValueError` 异常。
- **`lower()` / `upper()`**: 将字符串中的所有大写/小写字符转换为小写/大写。
- **`startswith(prefix)` / `endswith(suffix)`**: 检查字符串是否以指定的前缀或后缀开头/结尾，返回布尔值（`True` 或 `False`）。
- **`isdigit()`**: 如果字符串只包含数字则返回 `True` 否则返回 `False`。
- **`isalpha()`**: 如果字符串至少有一个字符并且所有字符都是字母则返回 `True`。

class Solution:
    def reverseWords(self, s: str) -> str:
        return " ".join(s.strip().split()[::-1])
